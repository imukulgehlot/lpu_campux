# 📱 LPU CampuX

A modern Flutter-based UI showcase app that reimagines the experience of LPU Online. Built with modular architecture, smooth animations, and GetX-powered navigation, CampuX offers a visually rich, student-centric app demo.

---

## 🚀 Features

- 🔐 Login & Onboarding Screens
- 🧭 Bottom Navigation Bar with blur & animation
- 🗞️ Explore Tab
    - Carousel with university features
    - Announcements (HTML rendered)
    - Notifications
    - ID Card, Program Guide

- 📘 Learn Tab
    - E-Tutorials with progress bar
    - E-Content with PDF download/viewer (Syncfusion)
    - 
---

## 🛠️ Tech Stack

| Tool                  | Purpose                          |
|-----------------------|----------------------------------|
| **Flutter**           | UI framework                     |
| **Dart**              | Core programming language        |
| **GetX**              | Routing, state management        |
| **flutter_html**      | Rendering announcement content   |
| **syncfusion_flutter_pdfviewer** | E-content viewer          |
| **flutter_animate**   | Animations & transitions         |
